 # 客服标准操作流程 (Customer Service SOP)

 ## 一、工作原则

 ### 1.1 核心原则
 - **响应速度**：客户咨询在 24 小时内响应
 - **态度温度**：耐心、专业、有同理心
 - **处理闭环**：每个问题必须有始有终
 - **记录完整**：每次客户交互必须记录

 ### 1.2 工作范围
 - 售前咨询（产品、配送、支付等问题）
 - 售中服务（订单处理、物流跟踪）
 - 售后服务（退换货、投诉、评价管理）
 - 客户关系维护（复购引导、关怀邮件）

 ---

 ## 二、售前服务流程

 ### 2.1 FAQ 自动回复
 - 客户常见问题优先引导至 FAQ 页面
 - 通过 API 自动匹配 FAQ 关键词并回复
 - 未匹配到的问题转人工客服

 ### 2.2 人工售前咨询
 1. 确认客户咨询类型（产品/配送/价格/其他）
 2. 回答产品相关问题（泥料、工艺、容量、适用茶类）
 3. 提供物流和关税信息
 4. 引导客户下单

 ### 2.3 售前话术要点
 - 介绍宜兴紫砂文化，突出手工价值
 - 说明全球配送和 30 天退换政策
 - 强调紫砂壶开壶和养护知识

 ---

 ## 三、订单处理流程 (售中)

 ### 3.1 接收订单
 1. 独立站推送新订单
 2. 客服检查订单信息完整性
 3. 确认支付状态（已支付/待支付）
 4. 记录到客服跟踪系统

 ### 3.2 供应商下单
 1. 将订单转发给宜兴供应商
 2. 确认库存并锁定商品
 3. 获取预计发货时间
 4. 更新订单预计发货日期

 ### 3.3 国际物流发货
 1. 根据客户选择的物流方式安排发货
 2. 国际小包（10-15 天）/ 国际专线（7-10 天）/ DHL 快递（3-5 天）
 3. 获取物流单号
 4. 打包并贴好国际面单
 5. 回填物流单号到订单系统

 ### 3.4 物流跟踪
 - 发货后 3 个工作日主动更新物流信息
 - 追踪异常（滞留/退运/清关延误）及时通知客户
 - 客户查询物流时在 12 小时内回复

 ### 3.5 订单状态更新
 | 状态 | 说明 | 客户通知 |
 |------|------|---------|
 | pending | 待支付 | 无 |
 | paid | 已支付 | 确认邮件 |
 | processing | 配货中 | 配货通知 |
 | shipped | 已发货 | 发货邮件（含物流单号） |
 | delivered | 已签收 | 签收确认，邀请评价 |
 | cancelled | 已取消 | 取消确认/退款通知 |

 ---

 ## 四、售后服务流程

 ### 4.1 退换货处理
 1. 客户提出退换货申请
 2. 确认是否符合退换货条件（30 天内、不影响二次销售）
 3. 收集必要信息：订单号、问题描述、照片/视频
 4. 判断责任方
 5. 质量问题/运输损坏 → 我方承担退货运费
 6. 客户原因 → 客户承担退货运费
 7. 给出处理方案：退货退款 / 换货 / 部分退款
 8. 发送退换货指引（地址、注意事项）
 9. 收到退回商品后 3 个工作日内处理
 10. 结案并记录

 ### 4.2 退款处理
 - **PayPal 退款**：登录 PayPal → 退款 → 3-5 个工作日
 - **Stripe 退款**：登录 Stripe Dashboard → 退款 → 5-10 个工作日

 ### 4.3 投诉处理
 1. 耐心倾听，不打断客户
 2. 表示理解并道歉（无论责任在哪方）
 3. 记录投诉内容
 4. 提出解决方案
 5. 跟进到满意为止
 6. 结案后记录到投诉案例库

 ### 4.4 客户评价管理
 - 签收后 3-7 天发送评价邀请邮件
 - 好评（4-5星）：感谢客户，邀请晒图
 - 中评（3星）：了解原因，主动改进
 - 差评（1-2星）：72 小时内联系客户，了解问题，争取解决后修改

 ### 4.5 复购引导
 - 签收后 30 天发送养护提示邮件（附带新品推荐）
 - 签收后 90 天发送老客户专属优惠
 - 节假日发送关怀问候
 - 新品上线时通知老客户

 ## 六、交接班流程

 1. 检查未处理工单数
 2. 列出需要跟踪的问题
 3. 记录重要沟通进度
 4. 交接未完成事项
 5. 接班同事确认接收
