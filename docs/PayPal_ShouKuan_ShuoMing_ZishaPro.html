PayPal Integration Details

  • Integration method: PayPal JavaScript SDK (REST API) embedded in checkout page
  • Data security: Customers redirected to PayPal official page for login; sensitive payment data handled by PayPal directly
  • IPN: PayPal IPN configured for automatic order status updates on successful payment
  • Currency: Accept USD; PayPal handles currency conversion automatically
  • Refunds: Full or partial refunds via PayPal API
  • Guest checkout: Support credit card payments without PayPal account
