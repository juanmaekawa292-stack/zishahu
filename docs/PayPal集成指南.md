# PayPal 收款接入指南 — 紫砂雅集 (ZishaPro)

## 一、PayPal 账户类型选择

你申请时看到的页面提示选择 **"个人"或"商业"账户**。对于独立站收款，必须选择 **商业账户 (Business Account)**。

| 类型 | 适合 | 能否用于网站收款 |
|------|------|:--------:|
| 个人账户 (Personal) | 个人之间转账、网购付款 | ❌ 不能用于商业收款 |
| 商业账户 (Business) | 独立站、电商收款 | ✅ 必须选这个 |

---

## 二、注册商业账户所需材料

### 中国大陆用户注册 PayPal 商业账户
PayPal 对中国大陆用户是开放的，不需要香港公司或香港手机号。

**你需要准备：**

1. **企业/个人身份** — 如果你是个体户/个人卖家，选"个人商家"
2. **身份证** — 中国大陆身份证
3. **手机号** — 中国大陆手机号（+86）
4. **邮箱** — 用来登录 PayPal（建议用 zishapro@163.com 或单独注册一个）
5. **银行卡** — 用于提现（国内银行的 Visa/Mastercard 储蓄卡或信用卡）

### 注册步骤

1. 打开 https://www.paypal.com/business 点击"注册"
2. 选择 **"商业账户"**
3. 填写邮箱、密码
4. 选择国家/地区 → **中国 (China)**
5. 填写商家信息：
   - 商家名称: Zisha Art Studio（或你的品牌名）
   - 经营类型: 零售 / 工艺品
   - 网站: https://zishapro.com
6. 关联银行卡（用于提现）

## 三、网站集成方式

### 方案 A：PayPal 标准支付按钮（推荐，最快）

PayPal 提供直接在网站嵌入"Pay with PayPal"按钮的方式，流程如下：

**客户操作流程：**
1. 在 zishapro.com 选好商品 → 去结算
2. 点击 **"Pay with PayPal"** 按钮
3. 跳转到 PayPal 登录页面
4. 登录 PayPal 账号确认支付
5. 支付成功，跳转回 zishapro.com

**你需要做的事情：**
1. 注册 PayPal 商业账户 ✅
2. 登录后获取 **Client ID**（在 Developer Dashboard 里）
3. 把 Client ID 配置到网站后台
4. 网站已经内置了 PayPal SDK 支持

### 我可以在管理后台的支付设置里配置，之后客户结算时就能看到 PayPal 选项。

也可以搭配现有的**连连支付**一起用，让客户自由选择。

## 五、常见问题

**Q: 客户用美元支付，我能收到人民币吗？**
A: 可以。PayPal 会自动按汇率转换，也可以选择保留外币余额。

**Q: 提现到国内银行卡要多久？**
A: 通常 1-3 个工作日。

**Q: 客户没有 PayPal 账号能付款吗？**
A: 可以。PayPal 支持"Guest Checkout"，客户可以用信用卡直接付，无需注册 PayPal。

**Q: 跟连连支付比哪个更便宜？**
A: 连连收单费率通常更低（1-2%），但连连主要面向中国大陆商家做跨境收款，需要企业资质审核。
PayPal 费率较高（4.4%）但门槛低，客户信任度高（全球买家都知道 PayPal）。

**建议：两个都开，让客户在结算时自由选择。**
